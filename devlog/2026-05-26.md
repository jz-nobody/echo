Confirmation panel stability + collapse animation polish

## 已完成
- PanelState.mouseExited() 增加 guard 防止 confirmation panel 被 400ms timer 自动收起
- NotchRootView 在 panel 展开时刷新 confirmation queue（覆盖 hover 路径）
- WindowController collapse 动画改为：瞬间收缩高度 + 仅动画宽度收窄，消除 compact bar 垂直漂移
- barHostingView 从 isHidden 切换为 alphaValue 控制，消除显示延迟
- ClaudeCodeAdaptor 重构：增量缓存 subagents/todos
- 新增 SessionState model 和 IPC protocol 更新
- 声音文件重命名

## 遇到的问题
- macOS window clipping 导致动画期间 subview 超出 frame 被裁剪
- autoresizingMask 触发 model layer 立即跳变，与 Core Animation 冲突
- isHidden 切换有 100-150ms 渲染延迟

## 做出的决策
- 拆分动画：高度瞬间收缩（无动画），仅宽度做 0.25s ease-in-out 动画
- 使用 alphaValue 替代 isHidden 保持 SwiftUI 预渲染
