## 遇到的问题
- actor 隔离要求 startMonitoring/stopMonitoring 必须通过 Task 异步调用
- SessionFileWatcher 的 onChange 回调需要 @Sendable 标记
- Bundle.module 在 SPM executableTarget 中不可用，保留 Bundle.main + fallback 方案
- macOS 安全限制阻止 osascript 发送按键（需要辅助功能权限）
- HookInstaller 的 .prettyPrinted + .sortedKeys 会重新格式化 settings.json（功能无影响）

## 做出的决策
- 使用 Unix domain socket 而非 HTTP 做 IPC（低延迟、无端口冲突）
- 适配器缓存内部状态（由 hook 事件更新），被 SessionManager 轮询时直接返回缓存
- 不解析 JSONL 日志文件（太复杂且脆弱），仅依赖 session 文件 + hook 事件推断状态
- Hook 超时设为 86400s（24h），与 VibeIsland 一致
- Bridge 脚本在 Agent Island 未运行时返回 {"decision":"ask"}（优雅降级）
- 保留 Bundle.main（fallback script 功能等价，executableTarget 不支持 Bundle.module）
